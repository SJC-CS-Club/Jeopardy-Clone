# 🧠 Computer Science Club Jeopardy

Welcome to the **Computer Science Club Jeopardy Game!**  
This is a fun, interactive quiz game built entirely with **HTML, CSS, and JavaScript**. No frameworks, no libraries, just pure web fundamentals 🎯

This project was made for the **San Jacinto College Computer Science Club** to make learning programming more engaging.  
It’s designed like the classic _Jeopardy!_ TV show, complete with categories, dollar values, and hidden answers.

Each category contains 5 questions ranging from **$100–$500**, with increasing difficulty!

---

## 🚀 Features

- ✅ 100% Vanilla **HTML**, **CSS**, and **JavaScript**
- 🧭 Interactive Jeopardy board with clickable question tiles
- 🗂 Organized categories and scores
- 🧠 Easily customizable questions (just edit the data!)

---

## 🧰 Tech Stack

| Tool           | Purpose                                 |
| -------------- | --------------------------------------- |
| **HTML5**      | Structure of the board and modals       |
| **CSS3**       | Styling, layout, and transitions        |
| **JavaScript** | Game logic, event handling, and scoring |

## 🧑‍💻 How to Run It

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/jeopardy-clone.git
   ```

2. Open the project folder:

```bash
   cd jeopardy-clone
   ```

Next, use the extension `live server` from VS code extensions to view the project!
